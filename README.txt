# Personal Portfolio Website

## Files
- `index.html` — page structure and content
- `style.css` — responsive design, animations and layout
- `script.js` — mobile menu, scrolling, reveal animations, active navigation, back-to-top and contact-form validation
- `resume.pdf` — add your own PDF resume with this exact filename

## How to run
1. Extract the ZIP.
2. Open `index.html` in VS Code.
3. Use Live Server, or simply open `index.html` in a browser.

## Personalize it
Search in `index.html` for:
- `your.email@example.com`
- `linkedin.com/in/yourusername`
- `github.com/yourusername`
- Project titles/descriptions/links

Replace the demo project information with your real projects.

## Resume
Put your PDF resume in the same folder and name it:
`resume.pdf`

## Important
The contact form currently performs front-end validation only. To actually receive messages, connect it to a backend or a form service later.
